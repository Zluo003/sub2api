```text
https://github.com/Zluo003/sub2api
```

## What This Fork Adds

- A new `video` platform.
- OpenAI-style async video APIs:
  - `POST /v1/videos`
  - `GET /v1/videos/{id}`
- Seedance 2.0 and Seedance 2.0 fast gateway support.
- Aigod API-key upstream account support for video generation.
- Admin-side video groups and pricing rules by model, resolution, and duration.
- Video usage billing, refund records for failed tasks, endpoint metadata, and duration metadata in usage logs.

## Development With Local Docker Image

```bash
cd /Users/zluo/Dev/sub2api
docker build -t sub2api:dev .
cd deploy
docker compose -f docker-compose.dev.yml up -d
```

Open:

```text
http://127.0.0.1:8080
```

Local runtime data is stored under:

```text
deploy/data/
deploy/postgres_data/
deploy/redis_data/
```

Do not commit runtime data or database backups.

## Docker Deployment

Default production image:

```text
ghcr.io/zluo003/sub2api:latest
```

Prepare a deployment directory:

```bash
mkdir -p sub2api-deploy
cd sub2api-deploy
curl -sSL https://raw.githubusercontent.com/Zluo003/sub2api/main/deploy/docker-deploy.sh | bash
docker compose up -d
```

## Script Install

The original one-line Linux installer is kept and now points to this repository:

```bash
curl -sSL https://raw.githubusercontent.com/Zluo003/sub2api/main/deploy/install.sh | sudo bash
```

It installs the binary to `/opt/sub2api`, configures `/etc/sub2api`, and creates the `sub2api` systemd service.

This installer requires GitHub Release assets generated by the release workflow. Source builds and local Docker development images are not suitable targets for the binary updater.

## Admin One-Click Update

The admin update feature is kept. It checks:

```text
https://github.com/Zluo003/sub2api/releases/latest
```

It is intended for release binary deployments. After a successful update, restart the service.
